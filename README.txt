# 경원남도교육청 업무포털 — Vercel 정리본

## 폴더 구성
- `index.html`: 화면 및 페이지 마크업
- `css/style.css`: 디자인/CSS
- `js/app.js`: 화면 동작 JavaScript

## Vercel 배포
1. 이 폴더의 파일을 GitHub 저장소에 올리거나, 폴더를 Vercel에 배포합니다.
2. 정적 HTML 사이트이므로 별도 빌드 명령은 필요하지 않습니다.
3. Output Directory는 프로젝트 루트(기본값 `.`)로 두면 됩니다.

## 데이터베이스 연결 전 확인
- 이 정리본은 원래 파일의 화면과 기존 동작을 유지하도록 CSS와 JavaScript를 분리한 것입니다.
- 현재 원본의 저장 방식은 브라우저 `localStorage` / `sessionStorage`를 사용하는 부분이 있습니다. 따라서 이 상태만으로는 여러 기기에서 데이터가 공유되지 않습니다.
- Firebase 연결은 아직 추가하지 않았습니다. 데이터베이스를 연결할 때 `js/app.js`의 저장/불러오기 로직을 Firebase SDK 사용 방식으로 변경하고, Firebase Console에서 보안 규칙을 설정해야 합니다.
- Firebase 웹 설정 값은 웹 클라이언트에 포함될 수 있지만, 서비스 계정 비밀키나 관리자 비밀키는 절대 프런트엔드 파일에 넣지 마세요.
- 실제 학생 개인정보가 아니라 테스트용 가상 데이터로 먼저 확인하세요.

## 참고
원본 페이지는 한 페이지 안에서 여러 화면을 전환하는 구조를 유지했습니다. 페이지마다 HTML을 따로 쪼개면 기존 화면 전환과 스크립트도 함께 수정해야 하므로, 우선 Vercel에 올리기 쉬운 `index.html + css + js` 구성으로 정리했습니다.
